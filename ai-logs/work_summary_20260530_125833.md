## Issues Encountered

### Help Text Was Too Tutorial-Like

- **Symptom:** `qi --help` was long and repeated examples across Quick Start, workflows, examples, scoped search, TOC, and pattern syntax sections.
- **Root Cause:** Default help carried both reference material and tutorial content that belongs in README/docs or a future examples command.
- **Fix:** Moved default help toward a compact reference shape and pointed users to deeper docs for examples.
- **Regression Risk:** `LOW`
- **Follow-Up:** Consider adding a dedicated `--help-examples` command if users miss the removed tutorial content.

### Configured Columns Needed To Stay Dynamic

- **Symptom:** Manually listing filter columns could drift from actual configured language support.
- **Root Cause:** Some columns, such as `scope` and `namespace`, are controlled by language feature configuration in `shared/column_schema.def`.
- **Fix:** Used X-macro expansion in compact help so filter and column alias output tracks enabled languages and future schema additions.
- **Regression Risk:** `LOW`
- **Follow-Up:** Consider separating compact help descriptions from longer schema docs if the generated descriptions become too verbose again.
