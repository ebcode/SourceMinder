## Work Completed

- **Fix 7:** `build_toc_query()` buffer truncation — replaced 13+ manual `snprintf`/`pos`/`remaining` sequences with a `TOC_APPEND` macro that checks for truncation after every write, returning `NULL` on overflow. Added `NULL` check at the call site.
- **Fix 8:** `add_entry_to_file()` uninitialized slot — added `memset(target_file, 0, sizeof(*target_file))` before `try_strdup_ctx()`, so a failed strdup leaves a clean zeroed slot instead of garbage. Removed now-redundant field assignments.
- **Fix 9:** Filepath separator normalization — replaced blind `"%s%s"` concatenation of directory+filename with a check that inserts `"/"` when directory is non-empty and doesn't end with `/`. Also added `NULL` guard on directory.
- **Fix 10:** File grouping O(files × rows) → O(1) common case — added `last_idx` cache parameter to `add_entry_to_file()`. Checks the cached index first; falls back to linear scan only on a miss. Updated forward declaration and call site.
- **Fix 11:** Import dedup O(n²) → O(n log n) — replaced linear duplicate scan with a sorted array using `bsearch()` for lookup and insertion-sort to maintain order. Added `cmp_import_symbols` comparator.
- **Fix 12:** Per-dot `printf` loop — replaced up-to-65 individual `printf(".")` calls with a single `printf` using `%.*s` precision on a static 72-char dot string.

## Notes / Design Decisions

- Used a `TOC_APPEND` macro (fix 7) scoped with `#undef` rather than a helper function to avoid changing the static buffer return pattern. A `SqlQueryBuilder` (as used in the web bridge) would be a cleaner long-term solution but was out of scope.
- Fix 8 uses `memset` to zero the entire struct rather than individual field assignments — matches the web bridge approach and is more defensive against future struct field additions.
- Fix 10 threads `last_idx` as a pointer parameter rather than using a file-level static, keeping the function reentrant.
