# SourceMinder Roadmap for 2026

1. Additional Languages: Perl, Rust. Perl is mostly there (as of June 2026). Rust needs more testing against real codebases.

2. Add guides for php, typescript, perl, and rust

3. Performance: Add multithreading to index files in parallel

4. Add --rows flag (or similar) to show only results, no help text, tips, or filtering info

5. Json-formatted output. (LLMs keep suggesting it.)

6. Test against larger codebases. (Tested against llvm-project, ~30k files, gives 7.2GB index, slow to query.)

7. Instrument queries (perf).

8. Automated tests. Gold output snapshots to prevent regressions.

## Not on the roadmap (yet)

1. Alternative Storage: Currently local Sqlite only. Consider MySql/Postgres or other backends, including remote Sqlite (could allow real-time collaboration on the same project).

## Not on the roadmap (ever)

1. Call graph functionality (which functions call this function, aka: dependency graph) -- there are better tools for this available. Keep this tool simple.
