This is *more* secure (nginx's hardened static path; the doc root is exactly the curated public source) and the perf cost is negligible for small cached files. The bridge contract is one function — `fetchSpan/fetchFile(path)` — so a batch API can replace the backend later without touching any C.

## Issues Encountered

### Empty/NULL/wildcard patterns in the highlight hot loop

- **Symptom:** an empty pattern matches everywhere and never advances the cursor → infinite loop (+ unbounded `WebOutput` growth); a NULL `patterns[p]` would crash; per-byte `strchr`/`strlen` was wasteful.
- **Root Cause:** the highlight loop re-derived literal patterns per byte and trusted every entry was a non-empty string. (The native CLI shares the empty-pattern infinite loop.)
- **Fix:** one-time precompute of `{ptr,len}` literals, filtering wildcards, NULLs, and empty strings; loop iterates only validated non-empty literals.
- **Regression Risk:** LOW — byte-identical for valid input; covered by harness.
- **Follow-Up:** NONE (native variant noted but out of scope).

### Out-of-range `source_location` columns → uninitialized-stack read (native UB)

- **Symptom:** trimmed lines could be emitted without a terminating newline, gluing onto the next line.
- **Root Cause:** native `print_lines_range` reads `line[end_column]` unconditionally; if metadata outruns the line it reads past the buffer.
- **Fix:** `emit_trimmed()` uses the real line length + last-written char; `parse_source_location_web` rejects negatives/reversed ranges. Logged as native fix #13.
- **Regression Risk:** LOW — parity-preserving for valid (snapshot-consistent) input.
- **Follow-Up:** apply native fix #13 on the CLI-fixes branch.

### `WebOutput` duplication / silent drift

- **Symptom:** `toc-web.c`'s `wo_steal` had quietly dropped the `len`/`cap` reset present in `qi-web-entry.c`'s copy.
- **Root Cause:** three independent file-static copies of the same accumulator.
- **Fix:** extracted to `shared-web/web_output.h` (single static-inline definition); migrated both modules.
- **Regression Risk:** LOW — verified clean compile under real build macros.
- **Follow-Up:** NONE.

### Source flags broken end-to-end (empty blob)

- **Symptom:** `-e`/`-C` showed "Could not read file" per match.
- **Root Cause:** step-3 landed the C side with the worker still passing `sourcesBlob = ''` (placeholder).
- **Fix:** implemented the `SourceCache` fetch + wired the real blob (steps 4–5) so C-side and worker land together.
- **Regression Risk:** LOW.
- **Follow-Up:** confirm `SOURCE_BASE` per deployment.

### Stale browser snapshot vs. served source (`qi malloc -C 3` mismatch)

- **Symptom:** first match's context aligned perfectly; a later match's line number didn't match the fetched source.
- **Root Cause:** dogfooding on a file edited all session — `code-index.browser.db` predated the edits, so indexed line numbers ≠ live source (snapshot-consistency invariant, plan §2). Compounded by WAL mode (a raw `cp` of `code-index.db` omits the `-wal` sidecar) and the browser HTTP cache.
- **Fix:** diagnosed; added a cache-bust (later superseded by Cache-Storage version keying); prescribed `wal_checkpoint(TRUNCATE)` + `journal_mode=DELETE; VACUUM` before copying.
- **Regression Risk:** NONE (test-setup artifact; non-issue for frozen demo repos).
- **Follow-Up:** re-index + regenerate snapshot, then verify end-to-end.

## Residual Risks / Not Verified

## Notes / Design Decisions

- **Static files, not an API** — same-origin; C/WASM renders (parity); **web twins** over a unified core (consistency with `toc-web.c`); **whole files into WASM**; length-prefixed framing (binary-safe vs. tab/newline/pipe in source).
- **Superset-of-files**: the worker fetches every displayed row's file; C alone decides per row what to render — keeps all parity logic in C, no duplicated decisions in JS.
- **`build_row_filepath` is the shared key** — the C formula and the worker's `buildRowFilepath` must stay identical (the blob lookup key).
- **Mandatory `qi`** — the command list mirrors a real qi invocation; only the literal first token is consumed (the earlier optional-strip caused the "first word ignored" confusion, which was actually OR-search of a no-match term).
- **`SourceCache.setBase` clears the cache** — an identical relative path is a different file in another project.

## Freeform Thoughts

The recurring theme this session was *parity under a moving boundary*: the twins had to match a CLI renderer that itself has latent UB, so "match native exactly" and "be correct" occasionally diverged (the `end_column` OOB read). Keeping native as the untouched reference and twinning into `shared-web/` made those divergences explicit and reviewable rather than silent.

The stale-snapshot episode was a useful real-world hit on the §2 invariant we'd only discussed abstractly — and it argues strongly for the `make snapshot` tooling idea, because a human (or AI) editing the indexed tree will hit it every time. The static-file bridge choice keeps paying off: every "is this broken?" turned out to be config (base URL, WAL, HTTP cache) rather than mechanism, which is exactly the failure mode we wanted.
