SourceMinder

SourceMinder is a collection of cli tools to aid in source code navigation and understanding. A handful of language-specific indexers (index-c, index-python, index-go, etc), and a unified query engine, query-index (qi).

SourceMinder was built with both humans and LLMs in mind. As a "context-aware grep", it helps human programmers avoid the false positives that come with regular searches. And for LLMs: compact output; flags to orient quickly on codebases; and clean output for Edit/Patch anchors.

The main idea is pretty straightforward. In code, the individual symbols take various forms. A symbol might be a function name, or a variable name. Or it might appear in a string or a comment. What if you could search your codebase with that context as a filter? So instead of "grep user", you could do "grep user --include function"? Or, "grep user --exclude comment"? That's what SourceMinder lets you do. To get started, run: qi --help
